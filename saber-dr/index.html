Method

How it works

  1. PreprocessingBlack borders are cropped, contrast is enhanced with CLAHE in the LAB color space, and the image is resized to 224 × 224 pixels.
  2. BackboneAn EfficientNet-B0 extracts retinal features; a global head and an ordinal head estimate the grade while respecting the order of the scale.
  3. Boundary expertsFour experts (E01, E12, E23, and E34) each specialize in telling two adjacent grades apart; a gate decides how much each one contributes.
  4. OutputEstimated grade, probability of each grade, whether the retinopathy is referable (moderate or worse), image quality, and the experts’ attention maps.

Research prototype

Web application

A server with an ensemble of five models trained with stratified cross-validation on APTOS 2019. It shows the grade, the probabilities, the agreement between models, and the attention maps. The image is processed in memory and never stored.

Android app

The model runs on the phone itself with ONNX Runtime, with no internet connection: the fundus image never leaves the device. The preprocessing exactly matches the web version.
