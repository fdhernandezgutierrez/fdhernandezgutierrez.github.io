Convolutional filters

A convolutional layer applies several filters to the same image, and each one produces a feature map. Here there are 16 filters of size 3 × 3.

Input image

How to use it

  1. Upload an image (JPG or PNG) or use the example.
  2. The image is converted to grayscale and reduced to 256 pixels per side.
  3. Each of the 16 filters slides over the image and gives a feature map. Bright areas are where the filter responds most.
  4. Tap a map to see it enlarged along with its filter values.
  5. Turn off ReLU to also see the negative responses (mid-gray = zero).

The image is processed in your browser; it is not sent anywhere.
